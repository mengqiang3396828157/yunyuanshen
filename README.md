# 资中二中 · 伪网页解密游戏 v4

一个 2003 年风格的重点中学校园网解密游戏。**纯静态 HTML，无框架、无 CDN、无外链、无音频文件。**

## 一句话概念

一个 2003 年建站的校园网，公告停更、图床全挂，**却一直在凌晨被登录维护**。

顺着"水塔值班记录"查下去，你会发现两个相隔八年的夜晚其实是同一件事：

> **2003 年 4 月 7 日夜里，老校工上塔检查水位计，没下来；**
> **2011 年 4 月 7 日夜里，一个学生在食堂留了一份夜宵，也没走。**

两条线共享的不是地点，是**"值夜班的人"**。
水塔是"上塔的人"，食堂是"留饭的人"——两个地方的怪谈本质是同一件事：
**深夜里有一个岗位需要被交接，而接班的人没有来。**

## 三个结局

| 编号 | 名称 | 触发方式 |
| --- | --- | --- |
| **A** | 留校 | `admin.html` 勾选「关闭日志」→ 首页顶出值班表 |
| **B** | 下塔 | `top.html` 输入任意名字 |
| **C** | 刷黑的板书（真结局） | 先读 `tearecord.html` + `blackboard.html` → 终章选「我不能留下」→ 写下那行字 |

> A 是被留下（循环继续）、B 是带走一个人（循环变轻）、C 是**结束这个岗位**（循环消失）。

## 跨线人物 · 向拆法

2011 年在读高二学生，唯一同时接触过两条线的人。七处线索分散在：
`oldpost.html`(X1/X6) / `blackboard.html`(X2) / `notebook.html`(X3) /
`canteen_night.html`(X4) / `photo2011.html`(X5) / `archive.html`(X7)

> X7 是全作最后一根钉：转学必须有接收学校。**接收学校一栏是空的。**

## 特殊机制

1. **4 月 7 日彩蛋**：仅当系统日期为 4 月 7 日时，首页滚动公告追加「今天不用上塔。」
2. **sitemap 隐藏页**：`sitemap.xml` 比导航多一条 `raw.html`
3. **回访记忆**：第二次打开首页时「今日访问」变 2

## 成就系统

共 24 个成就，存 `localStorage`（前缀 `zzez_`），右下角浮层可查看。
清空浏览器缓存 = 重置游戏。不联网、不写 cookie、不做任何数据上报。

## 本地预览

不要直接双击打开。在此目录下启动本地服务器：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000/index.html>

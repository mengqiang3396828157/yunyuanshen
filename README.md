# 资中二中 · 伪网页解密游戏

一个 2003 年风格的重点中学校园网解密游戏。**纯静态 HTML，无框架、无 CDN、无外链、无音频文件。**

## 一句话概念

一个看起来荒废多年却仍在更新的校园网，玩家顺着"水塔值班记录"查下去，
发现**有个人还留在上面**——而学校官网一直在替他打卡。

> 核心恐惧：不是鬼跳脸，是"这个网站有人在维护，而维护它的人已经不在了"。

## 三个特殊机制

1. **4 月 7 日彩蛋**：仅当系统日期为 4 月 7 日时，首页滚动公告追加「今天不用上塔。」
2. **sitemap 隐藏页**：`sitemap.xml` 列出的 URL 比导航多一条 `raw.html`
3. **回访记忆**：第二次打开首页时「今日访问」变 2，首条公告加注「（你昨天看到这里了）」

## 成就系统

共 20 个成就，存 `localStorage`（键名前缀 `zzez_`），右下角浮层可查看进度。
清空浏览器缓存 = 重置游戏。不联网、不写 cookie、不做任何数据上报。

## 本地预览

不要直接双击打开（部分浏览器对 `file://` 有限制）。在此目录下启动本地服务器：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000/index.html>

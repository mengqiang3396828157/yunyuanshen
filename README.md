# 资中二中 · 伪网页解密游戏

一个 2003 年风格的重点中学校园网解密游戏。纯静态 HTML，无框架、无 CDN、无联网请求。

## 一句话概念

一个看起来荒废多年却仍在更新的校园网，玩家顺着"水塔值班记录"查下去，
发现**有个人还留在上面**——而学校官网一直在替他打卡。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 校园网首页（入口） |
| `notice.html` | 通知公告存档 |
| `notice_2003.html` | 乱码页（第一层谜题） |
| `duty.html` | 值班记录（第二层谜题） |
| `admin.html` | 水塔水位监测系统（后台 + 结局分支） |
| `top.html` | 终章（水塔顶） |
| `oldpost.html` | 待删除的旧帖（支线） |
| `404.html` | 彩蛋页 |
| `style.css` | 公共样式（2003 年风格） |
| `common.js` | 公共脚本 |

## 谜题与答案

| 层级 | 位置 | 答案 |
| --- | --- | --- |
| 第一层 | `notice_2003.html` 乱码里唯二正常的字 | `二中` |
| 第二层 | `duty.html` 值班表里 4 月 7 日那一天 | `20030407` |
| 第三层 | 跨页收集三个片段 | `283146` |

**第三层线索分布**（必须跨页收集）：

- `2-8` → `index.html` 的 HTML 注释
- `3-1` → `notice.html` 公告编号「资二中〔2003〕3-1 号」
- `4-6` → `duty.html` 注释里的「水塔铁梯 46 级」

合成：`2-8` + `3-1` + `4-6` = `283146`，用于 `admin.html` 解密红线文字。

## 结局分支

- **A**：`admin.html` 点「关闭日志」→ 回首页，今日访问变 2，显示「已有两人查看。」
- **B**：`admin.html` 点「前往水塔」→ `top.html` 终章，输入名字生成值班记录

## 本地预览

不要直接双击打开（部分浏览器对 `file://` 有限制）。在此目录下启动本地服务器：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000/index.html>
